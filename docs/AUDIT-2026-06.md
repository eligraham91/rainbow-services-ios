# Start Here — Product & Engineering Audit

**Date:** June 2026 · **Branch:** `claude/exciting-tesla-UR4HS` · **Audience:** internal (Rainbow Services + dev)

This is a point-in-time audit of the Start Here iOS app: what is built, how it holds up, what is missing, and where it can go. Sections are ordered from "what exists" to "what could exist."

---

## 1. Executive summary

Start Here is a national, trauma-informed DV support app with no accounts, no analytics, and no server. Everything sensitive lives encrypted on the device. The build is feature-complete against the Phase 5b spec: four-tier navigation, a 16+ screen Tools spine, a 3,681-program national resource locator, an encrypted vault with biometric gate, a full safety-plan wizard with PDF export, a fake-call suite, and an operational-safety How-To library.

The app's defining engineering trait is that **safety is architecture, not copy**: Quick Exit clears the navigation stack, the app-switcher snapshot is masked, the panic screen impersonates a weather app, calls require two taps, and the discreet dark theme extends to the privacy mask itself.

Top three priorities coming out of this audit:
1. **Spanish localization** — the org serves survivors in English and Spanish; the app is English-only. This is the largest gap between mission and product.
2. **Asset completion** — ringtone, app icon, splash (all placeholders); blocks App Store submission.
3. **Token hygiene** — an EXPO_TOKEN was previously committed in `package.json` (now removed, but present in git history; rotate it).

- Runtime policy must stay `sdkVersion` (switching to `appVersion` breaks Expo Go).

## 3. Feature inventory

### Navigation (four-tier)
- **Tier 0 chrome:** Quick Exit (red ×, rightmost in tab bar): Warning haptic → `dismissAll()` → `/stealth`. Shake-to-exit does the same. PrivacyOverlay masks the app-switcher snapshot. Stealth screen impersonates a minimal weather glance; long-press (800ms) returns.
- **Tier 1:** GlassTabBar — 4 tabs (Home, Find Help, Tools, Vault), morphing spring highlight pill, blur + theme tint, instant tab switches.
- **Tier 2:** Tools nested stack with native `ios_from_right` spring transitions and swipe-back.
- **Tier 3:** Root modals (Emergency, Support, About).

### Home
3-door entry (Emergency / Understand / Support), SwipeToCall hotline slider (310-547-9343) with haptic ticks, `CALL 911 NOW` danger line, About link.

### Emergency (modal)
CALL 911 NOW button (direct dial by design), National DV Hotline + Rainbow local line via two-tap CallSheet, 6-chip triage (shelter / talk / legal / children / pets / other), mandatory-reporting caveat, link into resources.

### Find Help (resources)
3,681-program national dataset, ZIP/city/state search via bundled ZIP-centroid haversine lookup (no geolocation permission), service filters, distance badges, statewide-record badges, session-only Safe List with plain-text clipboard export (no app name in the export), confidential-address policy enforced at the data layer.

### Tools spine (7 categories)
| Category | Screens | Mechanic |
|---|---|---|
| Center your body | breathe / listen / ground | LongPress-driven 4-7-8 Skia sphere; Pan-driven bezier wave + ambient volume; kinetic particle field with velocity-based warm/cool color |
| Decipher | text-thread / financial / coercion / cycle | DecoderEngine: iMessage-replica thread, tappable word pills → "functions as" chips → borrow-a-response copy; editorial screens |
| Make a plan | safety-plan / legal-prep / shelter-expectations / de-escalation | 6-step wizard → MMKV → PDF export (no app-name header) → vault banner; legal tree built but **gated** pending Rainbow legal review |
| Learn | definitions / state-laws / dating / talk-to-friend | Editorial screens; state-laws searchable with pinned national hotline |
| Secure vault | vault tab | Biometric gate, encrypted notes, plan summary, panic wipe ("Remove all saved data") |
| Fake call | config / waiting / incoming / incall | Caller name (persisted), 5 delay presets, lock-screen notification with deeplink, silent-switch-override ringtone, slide-to-answer, full iOS call replica with toggling mute/speaker, zero app branding |
| How-Tos | 5 categories, 23 entries | Dating apps, rideshare, device, social, reporting; numbered steps, honest caveats, official source links via in-app browser (`createTask:false`, no Safari history), last-verified dates |

### Design system
- Mode-aware `useTheme()` (warm light / warm dark), toggle in About, persisted in MMKV. **Every survivor-facing surface is now theme-aware** (completed this sprint).
- Skia mesh gradient: gyroscope tilt + scroll parallax (ScrollContext SharedValue), theme-aware colors.
- GlassCard (expo-blur), GlassSurface (reduce-transparency → solid → GlassView → blur), PressableScale (spring press compress, Reduce Motion fallback), CallSheet, ScreenScaffold, EditorialScreen, DecoderEngine, SwipeToCall, BackPill.
- Inter Tight 800/900 display, Inter body, JetBrains Mono eyebrows/disclaimers.
- Trauma-informed motion: `useTraumaInformedMotion()` gates every entrance and Skia animation behind Reduce Motion.

## 4. UX audit

### What is strong
- **Safety choreography is coherent.** Exit paths (Quick Exit, shake, backgrounding) all converge on the same masked/neutral states. The user never has to remember more than "hit the red ×."
- **Two-tap calling is now universal** (this sprint). Only 911 dials directly, by design.
- **Press feel.** Spring-compressed cards, haptic vocabulary (Light for navigation, Medium for commitment, Heavy for call trigger, Warning for exit), native stack springs with swipe-back.
- **Honesty in copy.** How-To caveats ("preference, not a guarantee"), Quick Exit wording that doesn't over-claim history deletion, mandatory-reporting caveats where confidentiality is claimed.
- **The fake call is convincing**: silent-switch override, lock-screen notification entry, plausible in-call grid with toggling buttons, no branding anywhere on the call surfaces.

### Friction points / risks
- **Vault relock loop:** backgrounding relocks the vault (correct), but returning re-prompts FaceID with no grace period. A 15–30s grace window after successful auth would reduce friction without much risk.
- **Resources list virtualization:** large result sets render in a plain ScrollView. State-wide searches (hundreds of records) will jank on older devices. Move to FlatList/FlashList with the entrance animation capped to the first screenful.
- **State-laws coverage:** 16 of 50+ states have named orders; the rest fall to the (well-written) empty state. Fine as a fallback, but completing the dataset is low-effort, high-trust.
- **Stealth discoverability tradeoff:** the "hold to return" hint at 18% opacity is intentionally faint; some users will not find their way back. Acceptable tradeoff, but worth a line in onboarding (which does not exist yet — see §8).
- **No first-run moment.** The app drops users on Home with no 10-second orientation to Quick Exit and privacy posture. A dismissible, skippable, *one-screen* explainer would raise safety-feature discovery without ceremony.
- **Legacy redirects:** `app/plan.tsx` and `app/understand.tsx` exist only as redirects; harmless, but they appear in typed routes.

## 5. UI audit

- **Dark mode is complete** across screens and chrome, including the PrivacyOverlay mask and mesh fallback (both were light-only until this sprint). DecoderEngine pills now derive tint from their bubble.
- **Typography hierarchy is consistent** (Inter Tight 900 display / mono eyebrows / Inter body) and Dynamic-Type-safe at header level via `adjustsFontSizeToFit`.
- **Remaining hardcoded surfaces (intentional):** stealth (black), fake-call screens (#1C1C1E iOS call gray), state-laws hotline pin (dark callout), EditorialScreen readout card. All are deliberate contrast blocks; documented here so they are not "fixed."
- **Dead-but-present components:** `SpringButton`, `SkeletonShimmer` (Phase 2 library, unused by screens, still import legacy `C`). Keep or delete; if kept, migrate to `useTheme()` for hygiene.
- **Assets are placeholders:** `icon.png`, `splash.png`, `adaptive-icon.png`, `favicon.png` are 1×1 PNGs. App Store blocker.
- **Ringtone is not bundled:** the fake call rings silently (vibration only) until `assets/audio/ringtone.m4a` ships. License clearance is a Rainbow sign-off item.

## 6. Backend / data architecture audit

There is intentionally **no backend**. The "backend" is:

| Concern | Implementation | Assessment |
|---|---|---|
| Sensitive storage | MMKV AES-256, key in iOS Keychain via SecureStore | Solid. Key never leaves Keychain; wipe path exists. |
| Resource data | `shelter-data.json` (3,681 records) bundled | Works offline, zero network fingerprint. Staleness is the cost — records age until an app update ships. Phase 6 (live API) trades fingerprint for freshness; if built, route through a privacy-preserving proxy with no query logging, and keep the bundled set as offline fallback. |
| Geo search | Bundled ZIP centroids + haversine | Excellent choice: no location permission, no reverse-geocode network call. |
| Analytics / telemetry | None | Correct for this product. Resist adding any. Crash reporting, if ever added, must be opt-in and scrubbed. |
| OTA | EAS Update, runtime `exposdk:54.0.0` | Working. Note: OTA can silently change a safety-critical app; consider release notes discipline. |
| Secrets | **EXPO_TOKEN was committed in `package.json`** (removed this sprint; in git history) | **Rotate the token.** Add a secret-scanning pre-commit hook or enable GitHub push protection. Stripe keys exist in the session environment for Phase 4+ donations; nothing references them in code (correct — and donations arguably do not belong in this app at all; see §9). |

## 7. Wow features (already built)

These are the things demos should lead with:
1. **Gyro + scroll parallax mesh background** — the ambient layer moves with both device tilt and scroll, on the UI thread, theme-aware, Reduce-Motion-gated.
2. **Fake call suite** — silent-switch-override ringtone, lock-screen notification → deeplink → full-screen iOS replica with working toggles. Best-in-class for this category.
3. **DecoderEngine** — iMessage-replica abuse-pattern decoder with tappable word pills and "borrow a response" clipboard copy. Genuinely novel interaction for psychoeducation.
4. **Somatic tools** — gesture-physical Skia interactions (hold-to-breathe sphere, drag-a-waveform listening, velocity-colored particle grounding).
5. **Safety choreography** — Quick Exit / shake / background-mask / weather-stealth as one coherent system.
6. **SwipeToCall** — deliberate-action hotline slider with haptic detents.

## 8. Gaps and missing tools

Ordered roughly by impact:

1. **Spanish localization (critical).** Rainbow serves EN/ES; "Call and say your language" is approved phrasing for interpretation. The app has zero i18n scaffolding. Recommend: `i18next` or Lingui, `expo-localization`, extract all strings (the brand-voice review surface already exists in `docs/`), ship ES as a first-class locale. This is the single highest-mission-value item on this list.
2. **App Store blockers:** real icon/splash assets, ringtone license, final QA on a physical device, App Privacy questionnaire (easy: "no data collected").
3. **Onboarding / first-run safety orientation** (one screen, skippable): Quick Exit, privacy posture, fake call exists.
4. **State-laws dataset completion** (16 → 50 states + DC + territories).
5. **Legal tree un-gating** — engine and data are built; blocked on Rainbow legal review, not engineering.
6. **Notification deeplink edge case:** cold-start tap (app killed) may race the router before the tools stack mounts; needs a queued-intent check on launch.
7. **Vault auth grace period** (see §4).
8. **List virtualization** in resources (see §4).
9. **Accessibility pass:** VoiceOver route-through of DecoderEngine pills and SwipeToCall (slider needs `accessibilityActions` increment/decrement or a tap-fallback), Dynamic Type at body level, contrast re-check in dark mode.
10. **Android:** currently iOS-shaped (blur fallbacks exist, but fake-call UI is an iOS replica and would read as fake on Android). Decide explicitly: iOS-only at launch is defensible.

## 9. New feature concepts (2026-class), filtered through the trauma lens

Every candidate below is evaluated against one question: **what happens if the abuser picks up the phone?** Several fashionable 2026 features fail that test and are listed as anti-features.

### Recommended — high value, privacy-compatible
- **Evidence journal (vault extension).** Timestamped, encrypted incident notes with optional photo attachments (EXIF-stripped), exportable as a dated PDF for protective-order filings. Pairs naturally with the existing vault + Print pipeline. Add per-state one-party-consent recording caveats (data file, content-reviewed) before any audio capture is considered.
- **Decoy vault PIN.** A second passcode that opens an empty vault. Standard in this category (e.g., covert apps); meaningful protection under coerced unlock. MMKV supports multiple instances; the auth machine already exists.
- **Disguised app icon (alternate icons).** iOS alternate icons let the user re-skin Start Here as a calculator/weather/notes icon. Low effort, very high stealth value. (App name in Settings/app-switcher remains; document the limits honestly, per brand voice.)
- **Trusted-contact check-in timer.** "If I do not check in by 10pm, text my sister this message + my plan PDF." Hard part is the delivery without a backend: schedule a local notification prompting the user to send a pre-composed SMS (no server, no silent sending — iOS will not allow silent SMS anyway, which conveniently matches the privacy posture).
- **Safety plan reminders via neutral notifications.** Opt-in, disguised wording ("Reminder: groceries"), deep-linking into the plan. The notification content must never reveal the app's purpose.
- **On-device-only "pattern noticing" (Apple Intelligence).** With iOS 26 foundation models running on-device, the decoder could optionally analyze a *pasted* text thread locally and highlight coercive patterns using the existing chip taxonomy. Strict constraints: on-device inference only, nothing persisted unless saved to vault, feature-flagged, content reviewed by Rainbow. This is the only AI feature that passes the privacy bar; cloud LLM analysis of survivor messages does not.
- **iOS 26 Liquid Glass adoption** — already scaffolded via `GlassSurface`/expo-glass-effect; lights up with the dev build. Free wow.
- **Audio loop for Listen** — the drag-volume mechanic exists; it controls silence until the CC0 loop ships.

### Worth exploring — medium effort
- **Offline state-resource packs:** per-state coalition contact sheets (data exists in coalition directories), bundled like shelter-data.
- **Shelter "what to pack" checklist** with SwipeCheck rows, prefilled from the safety-plan documents step.
- **Quick Exit hardware shortcut:** Action Button (iPhone 15 Pro+) via App Intents → opens directly into stealth. Must be carefully named ("Weather Check") so the Shortcuts app does not leak intent.
- **Supporter mode deep-link:** a shareable route preset for friends/family that opens the app on Support content, making "share this app gently" concrete.

### Anti-features — fashionable in 2026, fail the abuser-test
- **Widgets / Live Activities / Dynamic Island:** anything glanceable on the lock screen advertises the app. Reject.
- **Siri / general App Intents exposure:** "Hey Siri, open Start Here" spoken aloud is a hazard; only the disguised Action Button shortcut above is defensible.
- **Cloud sync / accounts / iCloud backup of vault:** subpoenas, family-shared iCloud, and device-sharing all make this dangerous. Stay device-only and keep the vault out of backups (MMKV files should be marked `NSFileProtectionComplete` + excluded from iCloud — verify this is set in the dev build).
- **Push-notification campaigns / re-engagement:** any unprompted notification is exposure. Notifications stay user-scheduled only (fake call, opt-in reminders).
- **In-app donations (Stripe Phase 4+ keys exist):** mixing fundraising into a survivor tool muddies the no-data promise, adds Apple IAP/Stripe complexity, and puts a payment trail on a device that may be monitored. Recommend donations live on the website only; remove the keys from session env expectations.
